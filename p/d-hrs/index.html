D-HRS（链聘通）

链聘通HR合规存证

为「中大型企业 HR 合规负责人 / 法务 / 内审」而做

一句话

HR 流程的每一步，都留下一条司法级证据链。

解决什么问题

企业在等保评审、劳动仲裁举证、个保法与数据安全法审计时，拿不出不可篡改的操作记录——现在靠人工留痕，出事时各说各话。

三个核心能力

  • 合规引擎：链上 KYC + 制裁名单筛查 + 操作守卫
  • 员工存证 + 可验证凭证：入转调离全生命周期链上记录，薪资多签审批存证（金额不上链）
  • 全栈实现：合约 + Node 后端 + Web 单页 + React Native 移动端

已知的局限 / 不适合谁

定位是合规中间件，不替换北森 / Moka / 钉钉——客户必须先有 HR 系统；合规建设尚未完成（等保准备中、合约待第三方审计）；暂无独立官网，演示以截图/录播为主。
