一句话

所有 CTF 和黑客松的报名截止日，我每天早上 9 点推给你。

解决什么问题

参赛者最痛的是"报名截止了才知道"。手动刷 CTFtime、ETHGlobal、各赛事公众号，或在 Excel 里手抄截止日——多源、多时区、多格式，靠人必然漏。

三个核心能力

  • 多源抓取 + 学生赛事过滤：CTFtime / ETHGlobal / 手动清单 / DataFountain 等多源，自动过滤学生专属赛
  • 5 维评分 + 跨源去重：紧迫 / 影响 / 类型 / 信息量 / 完整度五维打分，按日期与标题重叠去重
  • 多通道通知 + 两个界面：终端、Telegram、邮件、Windows 弹窗，外加本地赛事仪表盘与桌面月历浮窗

已知的局限 / 不适合谁

多个数据源被反爬挡住，覆盖面依赖手工清单维护；本地 Windows / WSL 强绑定，跨平台使用者跑不起来。
